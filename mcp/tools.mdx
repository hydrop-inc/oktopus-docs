El MCP expone **71 herramientas**. La lista autoritativa siempre la devuelve `tools/list`; este es el catálogo por categoría:

## Negocio y métricas

| Tool | Qué hace |
|---|---|
| `okto_dashboard_metrics` | Resumen del negocio: ingresos 30d, órdenes pendientes, productos. |
| `okto_account_status` | Plan, estado de suscripción y límites de la cuenta. |
| `okto_audit_recent` | Actividad reciente de la cuenta. |

## Productos

| Tool | Qué hace |
|---|---|
| `okto_product_create` | Crear un producto (nombre, precio, descripción, imágenes). |
| `okto_product_update` | Editar un producto. |
| `okto_product_price_update` | Actualizar precio / precio tachado. |
| `okto_products_list` | Listar productos. |
| `okto_product_lookup` | Buscar por nombre. |
| `okto_products_delete` | Borrar productos. |
| `okto_products_duplicates` | Detectar duplicados. |
| `okto_product_normalize_name` | Normalizar nombres. |

## Imágenes IA del producto

| Tool | Qué hace |
|---|---|
| `okto_product_images_generate` | Generar el banco de imágenes IA del producto (6 básicas, 10 con gatillos mentales, o una lista propia; banco web o ads). |
| `okto_image_regenerate` | Regenerar una imagen puntual. |
| `okto_product_images_get` | Ver las URLs públicas de ambos bancos (web y ads) — p. ej. para armar creativos de Meta. |
| `okto_product_image_delete` | Borrar una imagen del banco. |

## Landings

| Tool | Qué hace |
|---|---|
| `okto_landing_generate_full` | **Generar una landing completa de cero** desde un producto: copy + paleta de colores + armado (con `auto_publish` opcional). |
| `okto_replicate_landing` | **Replicar una landing de referencia** (URL externa) con el producto propio — clona estructura y estilo. |
| `okto_landing_get` / `okto_landings_list` | Ver y listar landings. |
| `okto_landing_edit` | Editar una landing con una instrucción en lenguaje natural. |
| `okto_landing_publish` / `okto_landing_unpublish` | Publicar / despublicar. |
| `okto_landing_set_field` | Cambiar un texto puntual. |
| `okto_landing_set_branding` | Colores y marca. |
| `okto_landing_toggle_guarantee` | Activar/desactivar la garantía. |
| `okto_landing_status_set` | Publicar/ocultar. |
| `okto_landing_eject` | **Exportar la landing a código editable (HTML + React)** para self-host. |

| Tool | Qué hace |
|---|---|

| `okto_order_get` | Detalle de una orden + estado en Dropi. |

## Workflows (orquestación durable)

Para tareas largas de varios pasos (p. ej. "montá el producto X completo: importalo de Dropi, generale imágenes y landing y publicá"), el MCP trae un motor de workflows durable — sobrevive reinicios y se puede pausar/retomar:

| Tool | Qué hace |
|---|---|
| `okto_workflow_start` | Proponer un workflow (queda en borrador para revisar). |
| `okto_workflow_update_draft` | Ajustar el borrador antes de ejecutar. |
| `okto_workflow_execute` | Ejecutar el workflow aprobado. |
| `okto_workflow_list` | Listar workflows y su estado. |
| `okto_workflow_resume` | Retomar uno pausado o interrumpido. |
| `okto_workflow_cancel` | Cancelar uno en curso. |
| `okto_workflow_clear_drafts` | Limpiar borradores. |

## Tienda y soporte

| Tool | Qué hace |
|---|---|
| `okto_store_create` / `okto_store_get` / `okto_store_update_settings` | Crear y configurar tiendas. |
| `okto_store_delete` | Borrar una tienda (soft-delete). |
| `okto_support_ask` | Preguntarle al soporte de Oktopus. |
| `okto_support_resync_order` | Re-sincronizar una orden puntual con Dropi desde soporte. |
| `okto_memory_list` | Ver la memoria persistente del agente sobre la cuenta. |

<Note>
Con un token **OAuth**, las tools de generación de imágenes/video con IA (`okto_landing_generate_full`, `okto_product_images_generate`, `okto_image_regenerate`) **no aparecen** — están excluidas del conector. Con API key propia sí están disponibles.
</Note>
